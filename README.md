# مشاريع المدرسة

مجلد خاص يجمع كل ما يتعلق بالمدرسة في مكان واحد.

## البنية

- **فيديوهات/** — أي فيديو (شرح، تسجيل حصة، عرض تجريبي...)
- **ملخصات/** — ملخصات دروس أو مواد
- **عروض-تقديمية/** — ملفات PowerPoint أو عروض أخرى
- **ملفات-أخرى/** — أي شيء لا يندرج تحت التصنيفات أعلاه

ارفع الملفات مباشرة داخل المجلد المناسب — لا داعٍ لتنظيم إضافي أعمق إلا إذا احتجت ذلك لاحقًا.

> ⚠️ **ملاحظة عن الفيديوهات:** GitHub يرفض أي ملف أكبر من 100MB، ويُفضَّل ألا يتجاوز حجم المستودع كاملاً بضع مئات من الميجابايت. إذا كانت الفيديوهات كبيرة، أخبرني وسأُعدّ Git LFS أو نجد حلاً بديلاً (رابط تخزين خارجي مثلاً) بدل رفعها مباشرة هنا.
